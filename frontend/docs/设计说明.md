# 照渊台 · 设计说明

## 一、核心概念（198 字）

**照渊台**：一口渊，四盏灯，一叠帖。

渊是这座共享记忆库——水在渊里全楼通，沉底的是全量，悬在中层被照亮的是精炼。四盏灯立在渊边，一盏一个人格：焰稳的常明着，剩烬的要引火，风里的时明时灭。灯只照水，不照彼此——记忆是水，人格是房。

库主的全部动作只有两样：**投帖入水**，**打灯照水**。说话不是投进信箱，是把石子丢下去——涟漪推到谁的灯下，谁就爆芯醒来干活，火星一路落回水面；叫不醒的，帖子浮着变琥珀。

所以它长这样：因为四个人格共用一池水，各自关门。所以这样操作：因为凡是要他们动的事，都得先让水动。

## 二、使用者的一天（三条动线）

**其一 · 派个活**（约 20 秒）
`Alt+N` 起帖 → 收件人（键盘 1-4 点灯）→ 重量选「差帖」，此时渊面预演一枚铁锚的落点与深度 → `Ctrl+Enter` 投出。之后不用盯着：涟漪自己爬向那盏灯，灯爆芯，火星开始落（流式回传），回声环回投点。若九十秒叫不醒，帖子在水面转成琥珀，链上打一个折角——内容不丢，只是变成了留帖。差帖会自动进「差帖案」等回执。

**其二 · 看昨晚他们干了什么**（约 40 秒）
进台第一眼看渊：中层新浮起的那几颗是昨夜蒸馏出来的，还带着上浮的余速；石阶上正在溶解成沙的是今日淘汰的。灯下题名写着谁在、谁只能留帖。往下是四盏灯各自推上来的格子（`/api/widget`），其中有一格是「梦境」——两盏灯每周共同蒸馏一次，私密的那些只给条数，蜡是黑的。

**其三 · 查一条记忆为什么被淘汰**（约 1 分钟）
`Alt+4` 进渊谱 → 搜到那条 → 它已翻面成灰，一条「代」线从新事实指向它：**被取代**。若线是「争」（跨域视角分歧），它不会被取代，只是并列——两条都还在，因为分歧不等于错。若没有任何线指向它，看它的寿命环：环走完就是被时间带走的，而每盏灯的钟走得不一样快，所以同一条记忆在不同人那里死得不是同一天。

## 三、视觉与交互原则

1. **动效是信息**。每一个动效都必须能被一句"它在告诉我什么状态变了"解释（这些句子写在 `src/api/fates.ts` 的 `STATE_FACE`）。解释不出来的一律删。
2. **颜色是配额**。全站语义色只有五支：渊青（水与底）、素白（正文）、灯金（唯一的高亮/焦点/热度）、琥珀（超时降级）、朱（淘汰与危险）。理由：这台工具每天开几十次，颜色一多就不再是信号而是装饰；华丽感交给纹样、材质、层次与运动去背，不靠色相数量。
3. **华丽在纹与质，不在光晕**。缠枝、云雷、水波纹用内联 SVG 细描金线；渊面是自绘 Canvas 的真运动。禁止无意义发光。
4. **三种字**：题名用衬线，正文用系统无衬线，所有数字用等宽并右对齐——数字要能上下对齐着扫。
5. **封蜡是可信的视觉语言，不是权限文案**。私密条目呈现为黑蜡封+金线绞，看得见占位、看得见条数、读不到字。【不】写"您无权查看"——那是替权限系统道歉。
6. **视图之间有因果**。切视图不是换面板：投出去的那枚帖在渊里的位置会保持，进「帖案」它是同一枚，进「差帖案」它还是同一枚，颜色与状态延续。
7. **两套主题都要成立**：`deep`（夜渊，默认）与 `paper`（熟宣，白日）。不是反色，是两种材质。

## 四、我主动决定「不做」的三件事

1. **不做通知红点计数的全局角标堆叠**。未读只在灯下以焰高与灯芯亮度呈现。理由：红点是让人焦虑的设计，而这台操作台每天开几十次——第三天就会开始躲它。焰高传达同样的信息且不制造债务感。
2. **不做可拖拽自定义仪表盘布局**。理由：布局本身承载概念（渊在中、灯在缘、帖在侧），可自由拖动等于允许用户把概念拆散，换来的"个性化"在单人工具上几乎无收益。
3. **不做力导向图的自由漂浮**。渊谱用确定性布局（实体按 idf 分环、记忆按层与时钟定位）。理由：力导向每次打开位置都不同，破坏"我记得它在左下"的空间记忆——而空间记忆正是长期使用变顺手的来源。

## 五、七件必须被设计出来的事 · 落点对照

| 事实 | 设计落点（不是文案） |
|---|---|
| 四个主体能力/在线/速度不同 | 四盏灯的焰型、灯座材质、引火动作各不同；`can_answer_now=false` 时递帖按钮字面变「留帖」，且渊面预演不画唤醒涟漪 |
| 说话即上工 | 投帖 → 涟漪爬行 → 灯爆芯 → 火星流式落回 → 回声环回；超时则水面转琥珀 |
| 五种重量命运不同 | 投物形态五种（卵石/散石/铁锚/石印/风讯），沉底深度、是否拴链、是否爆灯芯全由四个命运位驱动 |
| 房间下有话题 | 房是渊边的石舫，话题是舫上的横档；轮次状态与「还没回话的人」以灯影缺位呈现 |
| 可见性三态 | 封蜡（黑蜡+金线绞）；定向共享则蜡上开一道缝，只有被点名的灯能照进去 |
| 会呼吸的库 | 两层水（沉底 raw / 悬浮 refined）、蒸馏上浮、检索光柱先扫中层落空才探底、命中回写热度、按各自时钟衰减、到期溶解成沙、被取代则翻面 |
| 他们之间有关系 | 灯与灯之间的暗金丝：亲疏定粗细、信任定亮度、人情债定方向流动；每周「梦境」是两盏灯之间浮起的一颗共同记忆 |
