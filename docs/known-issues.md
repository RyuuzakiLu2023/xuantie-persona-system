# 已知边界：源码提供与完成验证分开

本清单不把失败解释为跳过，也不以删掉通用功能作为修复。版本为未发布的 1.1.0.dev0。

## 安装与基础使用

- Ollama 是唯一已实现的向量协议；配置云端 OpenAI embedding URL 不会使它自动兼容。
- 无向量服务时使用关键词降级，第一次探测可能有等待；不能承诺与语义检索同效果。
- 库配置沿用生产解析顺序，Hermes 的 xtmem.yaml / memory_advanced 可能优先于数据库环境变量。隔离测试必须清除宿主变量。
- lookup 的部分关键词路径仍存在限额后过滤，返回数量可能不足。
- WAL/outbox/存根/回执与数据库一起构成恢复状态。单文件数据库备份不等于整套恢复。

## 自动整理

- 粗蒸馏不是事实裁判，不能把拼接压缩称作语义提炼；评判式链路需要使用者配置 LLM。
- 蒸馏只允许使用受权限约束的来源；评判输出不自动取得比原料更大的读者范围。
- 部分旧整理脚本有成功信号、截断、窗口领取、来源清理不改正文等遗留。各脚本的验证情况与默认启用策略以 distillation.md 为准。
- 不自动创建任何私人 cron，不以“命令能运行”代替定时任务已生效。

## 宿主接入

- Hermes provider 需要真正宿主的 MemoryProvider/RecallStatus 接口；测试桩只验证局部兼容，不能替代宿主运行。
- prefetch 使用生产的有限等待和晚到作废规则。冷启动可能错过当轮注入；不能通过任意拉长等待越过宿主 deadline。
- 显式记忆镜像只接新增，原件 replace/delete 尚未形成完整镜像同步。
- ZCode 的 Stop 是否派发由宿主决定；没有运行证据时，不宣称自动保存闭环。
- DSH SDK 版本和挂载方式须与使用者安装版本匹配；静态语法检查不代表完整宿主测试。

## 高级接口

- REST、消息、房间和图谱有既有权限与一致性边界，源码保留但不默认启动，不建议向不可信网络暴露。
- 本机 CLI 的角色和环境不构成操作系统安全隔离；能读取库文件或控制进程环境的人仍是可信维护者。
- 私人飞书桥不公开，相关镜像不提供；通用 A2A 需要使用者显式配置端点。
- 会话来源采集模块默认关闭且依赖宿主装配，保留模块不等于已经启用。

## 测试

保留的历史测试含私人目录布局与真实环境假设，尚未逐项迁移。新公开安装与核心合成套件单独报告；不把它们的通过称为整个历史 tests 全绿。当前验证记录见 public-validation.md。
