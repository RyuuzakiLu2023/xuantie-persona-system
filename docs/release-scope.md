# 完整公开整备范围（1.1.0.dev0，未发布）

## 目标

交付可由使用者自行部署的通用 XTMEM，不再以“只有五条命令”代替整套记忆产品。当前工作树恢复现役通用能力及必要依赖，保留实际验证状态；发布由维护者另行执行。

## 随源码交付

- 完整 CLI：存取、观察、追溯、维护、遗忘确认、重算向量、消息与房间、serve/doctor 等。
- 共用引擎：写入/观察、WAL、事务、来源与权限、检索准入、raw/refined、诊断、会话来源模块和消息辅助模块。
- 通用自动整理：粗蒸馏、窗口账本、评判提炼与提交；时间线、画像及共享来源依赖。调用者自行配置 LLM 和调度。
- Hermes、DSH、ZCode/MCP 接入源码和通用安装配置。
- 打包、合成示例与公开安装测试。

`memory` 名称是沿用的 Python 包名；`src/hermes-plugin/memory` 里的引擎不需要 Hermes，只有宿主 provider 需要兼容接口。

## 不携带维护者的私人部署

真实库及恢复状态、凭据、私人 `.env`/角色配置、真实会话夹具、私人飞书身份桥、私人 cron、桌面唤醒自动化、内部报告不进入公开交付。A2A 端点、展示角色、LLM 地址等由使用者配置，默认不连维护者的服务。

这不等于删除蒸馏、端接入等通用功能；私有配置与通用实现必须分开。

## 证据分类

1. 生产实现和历史成绩只证明对应来源，不自动证明导出的代码或 wheel。
2. 本轮公开合成测试和安装结果见 public-validation.md。
3. 真实 Hermes/DSH/ZCode 宿主、定时调度、远程授权和完整换机恢复未验证时如实标明。
4. HTTP/消息高级边界、Wiki与来源清理的已知问题列在 known-issues.md；源码存在不标成可开放远程生产。

不覆盖或重打已发布的 v1.0.0 标签。本工作树使用开发版本 1.1.0.dev0，不提交、不推送、不创建 Release。
